## 🧩 В чем проблема старых инструкций?

В сети популярны инструкции 10-летней давности, предлагающие использовать классический пинг `l2ping` по MAC-адресу телефона. На современных смартфонах и дистрибутивах Linux они **не работают** сразу по трём причинам:

1. **Глубокий сон iOS / Android:**  
   Ради экономии батареи мобильные ОС разрывают классическое Bluetooth BR/EDR соединение через 20–30 секунд после выключения экрана. В результате `l2ping` начинает выдавать ошибку `Can't connect: Host is down`, и ноутбук блокируется прямо во время работы, пока телефон лежит на столе.
2. **Несовместимость с Wayland:**  
   Старые скрипты используют `xset dpms force on` для включения экрана. В современных сессиях Wayland (elementary OS 8, Ubuntu 22.04/24.04, Fedora) утилита `xset` не функционирует.
3. **Безопасность PAM и экрана блокировки:**  
   Команда `loginctl unlock-sessions` не может просто так снять экран блокировки современного менеджера дисплеев (LightDM Greeter / Gala / GDM) без правильного взаимодействия с D-Bus шиной оконного композитора.

## 🌐 Архитектура решения и принцип работы

Вместо устаревшего классического пинга `bt-proximity` использует гибридный трекинг через **аппаратные HCI-команды контроллера**, системную шину **BlueZ D-Bus** и пассивное прослушивание **Bluetooth Low Energy (BLE)**:

```text
[ Смартфон (iPhone / Android / Watch) ]
             │
             ├──► Активный радиолинк (Bluetooth LE / BR-EDR):
             │    Аппаратное чтение мощности HCI_Read_RSSI (0x05 0x0005) каждые 1 с
             │
             └──► Спящий режим (глубокий сон iOS / темный экран):
                  Асинхронный фоновый D-Bus Connect зонд (страничный опрос за 1-1.5 с)
             ▼
[ Bluetooth-адаптер ПК (hci0) ]
             │
             ▼
[ BlueZ D-Bus Service (org.bluez) ]
             │
             ▼
[ Демон bt-proximity (Python 3) ]
       ├── Аппаратный замер силы сигнала: RSSI (dBm)
       ├── Экспоненциальное сглаживание шумов: EMA (0.6 * new + 0.4 * prev)
       ├── Защита от дребезга радиосигнала: Hysteresis Debouncing (3 тика)
       └── Отслеживание ручной блокировки экрана (Super + L / LockedHint)
             │
             ├──► [УХОД]: Сглаженный RSSI < Порога (напр. < -62 dBm или обрыв связи)
             │        │
             │        └──► loginctl lock-session + org.gnome.ScreenSaver.Lock
             │
             └──► [ПРИБЛИЖЕНИЕ]: Сглаженный RSSI >= Порога (напр. >= -55 dBm у стола)
                      │
                      ├──► org.gnome.Mutter.DisplayConfig (PowerSaveMode = 0)
                      ├──► loginctl activate + loginctl unlock-session
                      └──► org.gnome.ScreenSaver.SetActive(false)
```

## 🎯 Ключевые возможности

* **Аппаратная точность дистанции (HCI Read RSSI):** замер мощности сигнала происходит напрямую у Bluetooth-контроллера с точностью до миллисекунды, позволяя четко разграничивать зоны «у стола» (~1–1.5 м) и «отошёл» (~2 м).
* **Сглаживание радиопомех (EMA):** исключает ложные срабатывания, если вы просто повернулись в кресле или закрыли антенну рукой.
* **Работает со спящим экраном смартфона:** сопряженные iPhone и Android опрашиваются на аппаратном уровне без необходимости будить экран телефона.
* **Не требует прав root (`sudo`):** взаимодействие происходит через стандартные интерфейсы `dbus` и `loginctl` непривилегированного пользователя.
* **Энергоэффективность:** фоновый обмен радиоканала находится в режиме ожидания (Sniff / LE Connection interval), практически не расходуя аккумулятор смартфона.
* **Поддержка Wayland и X11:** нативное пробуждение дисплея через D-Bus интерфейс Mutter/Gala.
* **Защита от перехвата при ручной блокировке:** если вы нажали `Super + L`, авторазблокировка временно отключается, требуя ввода пароля на клавиатуре.
* **Управление в 1 команду:** глобальная консольная утилита `bt-proximity` с режимами `status`, `monitor`, `config`, `scan`, `install`, `uninstall`.

## ⚡ Быстрый старт (Автоматическая установка)

### Шаг 0. Предварительное сопряжение
Чтобы система знала устройство, привяжите его в стандартных настройках Linux:
1. Откройте **Параметры системы $\rightarrow$ Bluetooth** на компьютере.
2. Включите Bluetooth на телефоне и нажмите **«Подключить / Связать»** (подтвердите код сопряжения).

### Шаг 1. Клонирование и запуск установщика
```bash
git clone https://github.com/bratiska6-pixel/bt-proximity.git
cd bt-proximity
./install.sh
```

Установщик автоматически:
* Определит ваш дистрибутив и установит зависимости (`apt`, `dnf`, `pacman`, `zypper`);
* Запустит сканирование Bluetooth и интерактивный мастер;
* Создаст команду `bt-proximity` в `~/.local/bin/`;
* Установит и запустит фоновую службу systemd с автозагрузкой.

## ⚙️ Интерактивная настройка и калибровка дальности

При установке (или вызове `bt-proximity config`) мастер предложит настроить параметры:

1. **Выбор устройства:**
   ```text
   Найденные сопряженные устройства:
     [1] iPhone (Сергей) [Сопряжено] (88:6B:DB:D8:C8:03)
     [2] Ввести MAC-адрес вручную
   Выберите номер [1-2] (по умолчанию 1):
   ```

2. **Выбор профиля дальности:**
   * **`[1] Близко / Стол`** (`near`): блокировка при `RSSI < -68 dBm`, разблокировка при `RSSI >= -60 dBm` *(~1.5–2 м, калибровано под рабочее место и гашение естественных колебаний сигнала, рекомендуется)*;
   * **`[2] Очень близко`** (`very_near`): блокировка при `RSSI < -65 dBm`, разблокировка при `RSSI >= -58 dBm` *(~1 м от стола, сразу при любом отдалении)*;
   * **`[3] Средне`** (`medium`): блокировка при `RSSI < -76 dBm`, разблокировка при `RSSI >= -68 dBm` *(~3.5–5 м, в пределах комнаты)*;
   * **`[4] Далеко`** (`far`): блокировка при `RSSI < -84 dBm`, разблокировка при `RSSI >= -76 dBm` *(~7–10 м, при выходе в соседнюю комнату)*;
   * **`[5] Ручная калибровка`**: ввод персональных значений RSSI и времени подтверждения ухода.

3. **Блокировка с кнопки:**
   * **`[1] Требовать пароль`** *(рекомендуется для безопасности: телефон сам не снимет блокировку, если вы нажали Super+L)*;
   * **`[2] Разблокировать телефоном в любом случае`**.

Конфигурация хранится в `~/.config/bt-proximity/config.json`.

## 🔒 Особый режим: Ручная блокировка (Super + L)

Если вы уходите и хотите **гарантированно запереть компьютер на пароль** (даже если телефон остаётся лежать на столе):
* Нажмите клавиши **`Super + L`** (или пункт «Заблокировать» в системном меню).
* Демон мгновенно распознаёт ручное действие пользователя и переходит в статус `[MANUAL_LOCK]`.
* В этом режиме автоматическая Bluetooth-разблокировка **приостанавливается**: войти можно **только введя пароль на клавиатуре**.
* Как только вы ввели пароль — защита Proximity автоматически возобновляет работу.

## 📴 Поведение, если телефона нет рядом (забыт или разряжен)

Если вы забыли телефон дома или выключили его:
1. **При включении ноутбука:**  
   Служба стартует в фоне, не находит телефон за 3 секунды и **один раз блокирует экран**.
2. **После ввода пароля:**  
   Вы вводите пароль на клавиатуре и продолжаете работать. **Циклической блокировки не будет**: демон фиксирует, что экран уже заблокирован по удалению, и не шлет повторных команд блокировки.
3. **Авторазблокировка:**  
   Пока телефона нет рядом, экран защищается стандартно (паролем при неактивности или по `Super + L`).
4. **Когда телефон снова появится:**  
   Как только телефон окажется в зоне видимости, демон автоматически обнаружит его и вернется к обычному режиму слежения без перезапуска.
5. **Как отключить службу на весь день:**  
   Если вы ушли без телефона на весь рабочий день и не хотите, чтобы фоновый демон опрашивал эфир:
   ```bash
   bt-proximity stop
   ```
   А по возвращении включите обратно:
   ```bash
   bt-proximity start
   ```

## 🛠 Команды управления CLI

| Команда | Описание |
| :--- | :--- |
| `bt-proximity status` | Проверить статус службы в systemd, параметры и силу сигнала (RSSI) |
| `bt-proximity log on` / `off` | **Включить / выключить подробный отладочный лог** для диагностики |
| `bt-proximity log show` | Просмотреть последние записи из файла отладки `debug.log` |
| `bt-proximity log clear` | Очистить файл лога (освободить дисковое пространство) |
| `bt-proximity stop` / `pause` | **Приостановить службу** (удобно, если забыли телефон дома или выключили его) |
| `bt-proximity start` / `resume`| **Возобновить работу** фоновой службы |
| `bt-proximity restart` | Перезапустить фоновую службу |
| `bt-proximity monitor` | **Живой тест дальности**: показывает реальный уровень сигнала и статус в консоли без блокировки экрана |
| `bt-proximity config` | Запустить мастер перенастройки (сменить устройство, дальность или поведение пароля) |
| `bt-proximity scan` | Найти доступные и сопряженные устройства поблизости |
| `bt-proximity install` | Установить и активировать фоновую службу systemd |
| `bt-proximity uninstall` | **Полное удаление под ноль** (служба, бинарник, файлы, конфигурация) |

## 📝 Работа с логами и отладка (Debug Logging)

В программу встроен детальный кольцевой журнал событий с автоматической защитой от переполнения диска (`RotatingFileHandler`: максимальный размер файла 10 МБ, хранится 1 архивный бэкап).

### 📁 Где сохраняется лог?
Лог сохраняется в конфигурационном каталоге пользователя:
```bash
~/.config/bt-proximity/debug.log
```

### ⚙️ Управление логом через CLI:

* **Включить запись лога (для диагностики):**
  ```bash
  bt-proximity log on
  ```
* **Выключить запись лога (чтобы зря не писать на диск):**
  ```bash
  bt-proximity log off
  ```
* **Просмотреть последние 30 строк лога:**
  ```bash
  bt-proximity log show
  ```
* **Следить за логом в реальном времени:**
  ```bash
  tail -f ~/.config/bt-proximity/debug.log
  ```
* **Очистить лог (освободить дисковое пространство):**
  ```bash
  bt-proximity log clear
  ```
* **Проверить статус записи и текущий размер файла:**
  ```bash
  bt-proximity status
  ```

### 📖 Как читать записи в `debug.log`?
Каждая строка отчёта снабжена точным временем до миллисекунд и структурированными полями:
```text
[17:15:13.824] [HCI] Handle 256 (Classic): GRPR offset=0 -> est -54 dBm
[17:15:13.829] [TICK] state=locked   | conn=1 | hw_rssi=-54  | smooth=-57.0 | silent=0.0s | is_far=0 (away=0/5) | is_close=1 (near=2/2) | ss_active=1 | manual_lock=0
[17:15:13.840] [DECISION] Triggering UNLOCK: near_hits=2/2, RSSI=-57
[17:15:13.841] [ACTION] [17:15:13] >>> iPhone РЯДОМ (RSSI: -57 dBm). Разблокировка экрана...
```

* **`state`**: статус сессии (`unlocked` — разблокирован, `locked` — заблокирован, `manual_lock` — заперт вручную через Super+L);
* **`conn`**: наличие прямого соединения (`1` — Bluetooth-канал активен, `0` — телефон в глубокой спячке или вне зоны);
* **`hw_rssi` / `ble_rssi`**: аппаратный уровень радиосигнала в dBm (для Classic BT учитывается калибровка смещения Golden Range);
* **`smooth`**: сглаженное экспоненциальное значение RSSI (фильтрация естественных скачков при смене позы);
* **`silent`**: сколько секунд не поступало радиомаяков от устройства;
* **`away=X/5`**: счетчик подтверждений ухода (блокировка наступает только при непрерывных 5/5 тиках);
* **`near=X/2`**: счетчик подтверждений приближения (разблокировка срабатывает при 2/2 тиках у стола);
* **`DECISION`**: принятое решение алгоритма (`Triggering LOCK` или `Triggering UNLOCK`).

## 🧪 Тестирование и проверка работоспособности

1. **Проверка через монитор калибровки:**
   ```bash
   bt-proximity monitor
   ```
   ```text
   [17:04:30] [MONITOR]     У СТОЛА (БЛИЗКО)  | RSSI: -48 dBm (raw: -48) | Молчит: 0.0с
   [17:04:35] [MONITOR]     ОТОШЁЛ (ДАЛЕКО)   | RSSI: -65 dBm (raw: -67) | Молчит: 0.0с
   ```
2. **Проверка в боевом режиме:**
   Отойдите с телефоном от стола на 2 шага. Через 3 секунды экран заблокируется. Подойдите обратно к столу — экран мгновенно загорится и снимет блокировку.
3. **Просмотр системного журнала службы:**
   ```bash
   journalctl --user -u bt-proximity -f
   ```

> [!WARNING]
> **Особенность iPhone:**  
> Иконка Bluetooth в Пункте управления (шторке) iOS **не выключает Bluetooth полностью** (лишь временно отключает аксессуары, продолжая вещать BLE-пакеты). Для проверки ухода нужно либо физически отойти от стола, либо выключить тумблер в **Настройки $\rightarrow$ Bluetooth**.

## 🗑 Удаление и откат изменений (Uninstall)

Для полного и чистого удаления проекта с компьютера выполните:
```bash
bt-proximity uninstall
```
Скрипт корректно остановит и удалит юнит systemd, очистит команду `bt-proximity`, удалит файлы программы и настройки.
